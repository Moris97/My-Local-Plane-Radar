MLPR icon verification — real aircraft, real classification

Every registration MLPR's receiver has ever recorded a type code for (GET /api/stats/registrations, same source as the Stats view's own registrations table), run through the real classification chain (icon-classify.js) against the real shipped data/icon-types.json. This is Stage 4's real-data cross-check, running against this receiver's own traffic rather than guesses. Available in production (unlike /dev/icons and /dev/icon-types, which are dev-only) since it needs real accumulated data to be useful at all. Rows classified via the ADS-B category fallback or landing on unknown are highlighted — those are the ones worth adding to icon-types.json. Note: the military-only overrides table can't be exercised here (this page has no per-registration military-flag data), so a tanker/AWACS sharing a civilian type code will show its civilian classification, not special. Same reason there's no separate "category fallback" bucket here: the ADS-B category field also isn't stored per registration, so every row below either hits the type table (exact/prefix) or falls straight through to unknown — there's no middle stage to show.
